# Точка поэзии

Локальная версия поэтической платформы: авторские профили, публикации стихов, персональная лента, избранное, комментарии, новости, модерация и закрытый раздел для выбранных пользователей.

## Запуск

```powershell
cd C:\Users\simktom\Desktop\outputs\poetry-sovereign
python app.py
```

Сайт откроется по адресу:

```text
http://127.0.0.1:8780
```

Если нужен другой порт:

```powershell
$env:PORT=8781; python app.py
```

Внешние Python-пакеты и сборка через `npm` не нужны.

## Локальные аккаунты

В правом верхнем углу есть переключатель текущего пользователя. Он нужен только для удобной проверки ролей в локальной версии.

Для входа по почте можно использовать пароль:

```text
demo12345
```

Примеры аккаунтов:

- `admin@tochkapoeta.local` — администратор
- `irina-sol@tochkapoeta.local` — модератор
- `lina@tochkapoeta.local` — автор
- `marina@tochkapoeta.local` — читатель

## Возможности

- регистрация автора по почте и паролю;
- публичные страницы авторов с аватаром, соцсетями, подписчиками, подписками и просмотрами;
- публикация стихов с несколькими жанрами и стилем;
- поддержка произведений без названия: в ленте показываются первые слова текста;
- персональная лента рекомендаций с учетом лайков, подписок, жанров, стилей, поиска и просмотренных стихов;
- скрытие уже просмотренных публикаций для конкретного пользователя;
- лайки, комментарии, избранное и копирование ссылки на стих;
- удаление своих публикаций из профиля;
- новости редакции;
- жалобы на стихи с ограничением по времени;
- очередь модерации по словарю проверки;
- блокировка пользователей, удаление публикаций и комментариев;
- закрытый круг для выбранных пользователей, модераторов и администратора;
- админ-панель с ролями, блокировками и журналом действий;
- нижний блок с соцсетями проекта и ссылками на документы.

## Данные

SQLite-база лежит в `data/poetry.db` и создается автоматически. При первом запуске добавляется стартовая библиотека стихов, чтобы сразу можно было проверить ленту и рекомендации.

Аватары сохраняются в `public/uploads/avatars`.

## Безопасность

В коде уже есть базовые меры:

- параметризованные SQL-запросы;
- проверка ролей на сервере;
- экранирование пользовательского текста перед выводом;
- security headers;
- защита статических путей от traversal;
- журнал действий для модерации и администрирования;
- пароли в локальной версии хранятся как PBKDF2-хэш с солью.

Перед публичным запуском нужно отдельно добавить подтверждение почты, восстановление пароля, CSRF-токены, полноценные cookie-сессии, rate limiting, резервные копии и мониторинг.

## Юридические документы

Публичные страницы `/privacy`, `/cookies` и `/offer` сейчас содержат короткие рабочие тексты. Перед запуском с реальными пользователями их нужно заменить на документы, проверенные юристом.

Файл `LEGAL_RU.md` — инженерный чеклист для подготовки к юридической проверке. Это не юридическое заключение.
