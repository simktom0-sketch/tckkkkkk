# Бот «Точка поэзии»

Это рабочий бот для редакции «Точки поэзии». Автор присылает стих, указывает, под каким именем его публиковать, при желании оставляет ссылку на свой Telegram-канал, а дальше бот сам собирает заявку, показывает превью и отправляет всё в модерацию. Без лишней суеты, но и без хаоса в общем чате.

## Что он умеет сейчас

- `/start` открывает главное меню;
- кнопка «Предложить стих» запускает короткую пошаговую форму;
- если задан `NEWS_URL`, в меню появляется кнопка «Новости», которая ведет на сайт или канал редакции;
- бот принимает текст стихотворения, имя или псевдоним автора и ссылку на Telegram-канал;
- ссылку на канал можно пропустить;
- перед отправкой бот просит согласие на публикацию;
- пользователь видит готовое превью будущей публикации;
- в чат модерации отправляются данные отправителя и отдельно оформленный текст стихотворения;
- HTML-разметка экранируется, чтобы пользовательский текст не ломал сообщение.

## Сценарий автора

1. Автор открывает бота и нажимает «Предложить стих».
2. Отправляет текст одного произведения.
3. Указывает имя или псевдоним для публикации.
4. Добавляет ссылку на личный Telegram-канал или пропускает этот шаг.
5. Подтверждает согласие на публикацию.
6. Проверяет превью.
7. Отправляет заявку на модерацию.

После отправки автор получает подтверждение, а редакция видит заявку в рабочем чате.

## Что видит модерация

В чат модерации приходит два сообщения:

- карточка заявки: имя Telegram-отправителя, username, Telegram ID и ссылка на канал автора;
- готовый текст публикации: декоративная линия, стихотворение, подпись автора и ссылка на бренд проекта.

Так модератору не нужно собирать пост вручную: остается проверить текст и решить, публиковать его или нет.

## Настройки

Бот читает настройки из `.env`.

```env
BOT_TOKEN=токен_бота
MODERATION_CHAT_ID=id_чата_модерации
BRAND_NAME=точка
BRAND_URL=https://t.me/TochkaPoeta
```

`BOT_TOKEN` выдается в BotFather.  
`MODERATION_CHAT_ID` — ID группы, супергруппы или канала, куда бот отправляет заявки. Бот должен быть добавлен туда и иметь право писать сообщения.

`NEWS_URL` добавляет кнопку «Новости» в главное меню. Если переменная пустая, кнопка просто не показывается.

## Запуск локально

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python bot.py
```

Если токен не указан, бот остановится с ошибкой `BOT_TOKEN is not set`.

## Размещение

Проект подготовлен как фоновой worker:

- зависимости перечислены в `requirements.txt`;
- версия Python указана в `runtime.txt`;
- команда запуска описана в `Procfile`.

Для деплоя нужен сервис, который умеет постоянно держать Python-процесс запущенным. После деплоя в панели хостинга нужно добавить те же переменные окружения, что и в `.env`.

## Текущие ограничения

- состояние формы хранится в памяти, поэтому при перезапуске бота незавершенная заявка сбросится;
- нет базы данных и истории заявок внутри самого бота;
- нет админ-команд для одобрения или отклонения прямо из Telegram;
- бот принимает только текстовые сообщения.

## Планы по развитию

- добавить кнопки «Новости» и «Турниры» в главное меню;
- сохранять заявки в базу перед отправкой на модерацию;
- добавить статусы заявок: новая, на проверке, опубликована, отклонена;
- сделать inline-кнопки для модераторов;
- добавить защиту от слишком частых отправок;
- вынести тексты сообщений в отдельный конфиг, чтобы их можно было менять без правки кода.
